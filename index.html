Read the result carefully
“Two lines supported” means the algorithm found a geometrically plausible pair. It does not establish that they are the correct lane boundaries. The six Udacity sample photos have no official lane annotations here; the report measures output availability and sensitivity, not accuracy.
This classical method approximates lanes as straight lines. Curves, shadows, faded markings and lane changes can produce incorrect estimates. Width is measured in image pixels. This demonstration provides no driving control.
